OPTIONAL PERSONAL MUSIC

The build includes What Remains, an original reflective instrumental cue,
and Unseen Horrors by Kevin MacLeod under CC BY 4.0.

To replace the reflective cue, put an Ogg Vorbis file named reflection.ogg
in this Music folder (its parent folder contains AFTERIMAGE.exe) and restart the game.
The file must be encoded as Ogg Vorbis; renaming an MP3 is not conversion.
It loops automatically and uses Music Volume, dialogue ducking and the
existing transition into the combat score. Removing it restores the default.

Use a recording you have permission to include in your game. Purchasing a
soundtrack for listening does not by itself grant redistribution rights.
No NieR:Automata music is included in this download.

Update-v4.cmd preserves an existing Music/reflection.ogg in your target folder.
